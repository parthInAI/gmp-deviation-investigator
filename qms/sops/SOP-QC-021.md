> SYNTHETIC DOCUMENT. Fictional site (Ardmore Biologics). Not a real procedure.

## 1 Purpose
To make sure only tested and approved raw materials and feed solutions are used in FV-201.

## 2 Scope
Sugar feed solution, PAA, soybean oil, acid, base and media components.

## 3 Responsibilities
3.1 QC samples and tests each incoming lot.
3.2 QA releases the lot in the inventory system.

## 4 Procedure
4.1 Each lot is tested for identity and the attributes in its specification (for sugar solution: concentration, pH, bioburden).
4.2 A lot that is out of specification is rejected and an investigation is opened.
4.3 Lot numbers used in each batch are recorded in the batch record so they can be traced.
4.4 A raw material problem usually affects every batch that used the lot. If only one batch shows the effect, a raw material cause is less likely and must be supported by evidence such as lot-specific test results.

## 5 Records
Certificates of analysis; QC test records; inventory release records.
